### Step 2: Save Screenshots

**Windows Users:**
```
1. Press Win + Shift + S (Snipping Tool)
2. Select area to capture
3. Click "Save As"
4. Save to: C:\Users\aayus\Platform Analyser\screenshots\
5. Name exactly as: home.png, dashboard.png, etc.
```

**Or Use Browser DevTools:**
```
1. Open website in Chrome/Edge
2. Press F12 (open DevTools)
3. Press Ctrl + Shift + P
4. Type "Capture full size screenshot"
5. Save to screenshots folder
```

### Step 3: Verify Files

Make sure you have these exact filenames:
```
screenshots/
├── home.png
├── dashboard.png
├── charts.png
├── ai-insights.png
└── export.png
```

### Step 4: Commit & Push

```bash
git add screenshots/*.png
git commit -m "Add application screenshots"
git push origin main
```

### Step 5: Check on GitHub

1. Go to: https://github.com/Aayush9808/Coding-Platform-Analyzer
2. Open README.md
3. Verify all screenshots display correctly
4. If images show broken, check filenames match exactly

## 🎨 Screenshot Tips

### Quality Guidelines:
- ✅ Resolution: 1280x720 or 1920x1080
- ✅ Format: PNG (best quality)
- ✅ Size: Under 500KB each
- ✅ Content: Use real data (your profiles)
- ✅ Theme: Light mode for consistency

### What to Avoid:
- ❌ Blurry or pixelated images
- ❌ Wrong filenames (must match exactly)
- ❌ JPG format (PNG is better)
- ❌ Error screens or loading states
- ❌ Personal sensitive information
