# 📸 Screenshots Guide

## How to Add Screenshots

This folder should contain screenshots of the Platform Analyser application to be displayed in the README.

### Required Screenshots

Please add the following screenshots (use browser screenshot tools or Windows Snipping Tool):

1. **home.png** - Home page showing the input form
   - Visit: https://coding-platform-analyzer.vercel.app
   - Capture the main landing page with input fields
   - Recommended size: 1920x1080 or 1280x720

2. **dashboard.png** - Analytics dashboard with results
   - Enter some usernames and analyze
   - Capture the dashboard showing stats overview
   - Include the platform cards section

3. **charts.png** - Visual charts section
   - Scroll to the charts section
   - Capture the difficulty distribution and platform breakdown charts
   - Make sure charts are fully visible

4. **ai-insights.png** - AI insights section
   - Scroll to the AI insights card
   - Capture the personalized recommendations
   - Include the full insights card

5. **export.png** - Export buttons/options
   - Capture the export section with PDF, Excel, and Share buttons
   - Can be a close-up of the buttons area

### How to Capture Screenshots

#### Windows (Snipping Tool)
1. Press `Win + Shift + S`
2. Select area to capture
3. Save the image with the correct name

#### Browser (Chrome/Edge)
1. Press `F12` to open DevTools
2. Press `Ctrl + Shift + P`
3. Type "Capture screenshot"
4. Choose "Capture full size screenshot"

#### Using Browser Extensions
- **Awesome Screenshot** (Chrome/Firefox)
- **Nimbus Screenshot** (Chrome)
- **FireShot** (Chrome/Firefox)

### Image Guidelines

- **Format**: PNG (preferred) or JPG
- **Size**: Keep under 500KB per image
- **Resolution**: 1280x720 or higher
- **Quality**: Clear and readable text
- **Content**: Show actual data (your profiles or demo profiles)

### Alternative: Use Placeholder Images

If you don't have screenshots yet, you can temporarily use placeholders:
- Visit: https://placehold.co/
- Generate images like: `https://placehold.co/1280x720/1e293b/white?text=Home+Page`

### After Adding Screenshots

1. Verify all 5 images are in this folder:
   ```
   screenshots/
   ├── home.png
   ├── dashboard.png
   ├── charts.png
   ├── ai-insights.png
   └── export.png
   ```

2. Test the README:
   - Open README.md on GitHub
   - Check if all images load correctly
   - Verify image quality and readability

3. Commit and push:
   ```bash
   git add screenshots/
   git commit -m "Add application screenshots to README"
   git push origin main
   ```

## Tips for Best Screenshots

✅ **Do:**
- Use real data (your actual profiles)
- Capture in light mode for consistency
- Show completed analysis with all sections
- Include browser chrome for context
- Make sure text is readable

❌ **Don't:**
- Include sensitive personal information
- Use blurry or pixelated images
- Mix light and dark mode screenshots
- Capture error states or loading screens
- Include browser tabs or bookmarks
